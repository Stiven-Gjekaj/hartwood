# Getting help

## Understand the project

- [README.md](README.md) says what the project is and what state it is in.
- [docs/roadmap.md](docs/roadmap.md) holds the milestones, their exit tests
  and their results.
- [docs/DECISIONS.md](docs/DECISIONS.md) holds each design decision and the
  reason behind it.
- [AGENTS.md](AGENTS.md) sets the rules for anybody who changes this
  repository, human or agent.

## Ask a question or report a problem

- Search the existing
  [issues](https://github.com/Stiven-Gjekaj/hartwood/issues) first, in case
  somebody has already asked.
- If you found a bug, open a bug report.
- If you want a feature, open a feature request.

When a guest does not boot, say whether the same image boots on QEMU. That
tells the fault of the image from the fault of the emulator.

Do not use the issue tracker for security problems.
See [SECURITY.md](SECURITY.md) for how to report those privately.

## Contributing
